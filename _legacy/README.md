# Mã cũ để tham khảo

Gian 1 cũ "Thật hay giả?" (vuốt thẻ phân biệt tin lừa đảo) đã được thay bằng "Ai là Hacker?" (20/11/2026).

- `swipe-client.js`: giao diện vuốt thẻ (đấu phòng 20–50 người).
- `swipe-server.js`: chấm điểm lượt chơi một mình.
- `cards.json`: bộ tin nhắn mẫu (có thể dùng lại làm nội dung tuyên truyền).

Không file nào trong thư mục này được nạp khi chạy game.
